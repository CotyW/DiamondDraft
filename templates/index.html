Upload Your Own Projections

Use projections from any source for the projected season. Your files stay in this browser: they are read here and never uploaded to a server. Players your files don't cover keep their Marcel projection.

File format

Comma-separated (.csv) with a header row, then one row per player. Use one file for batters and one for pitchers; choose both at once. A file with an IP column is read as pitchers. Column names aren't case-sensitive, and other columns are ignored.

RequiredOptional
BattersName PA AB H HR2B 3B R RBI SB CS BB SO HBP SF
PitchersName IP SO (or K) BB ERG GS W L SV HLD H HR R HBP
BothMLBAMID, the MLB player id, for exact matching
  • Use season totals (counting stats). AVG, OBP, SLG, ERA, WHIP, FIP and K/9 are calculated from them, so rate columns in the file are ignored.
  • Players are matched by MLBAMID when the file has it, or else by name. Two players with the same name can't be told apart without the id, so those rows are skipped.
  • A stat left out counts as 0, which matters if your scoring uses it.
  • FanGraphs projection exports (Steamer, ZiPS, ATC, THE BAT, Depth Charts) work as they are: use "Export Data" on the projections page.
